# The Atlas

The Convergence Atlas — a calling-discovery instrument. Identify your core frequency (calling), the inverse frequency where attack concentrates, and a biblical blueprint for walking through it.

A single self-contained `index.html`: no build step, no frameworks, no tracking. The only external dependency is Google Fonts.

> These are archetypal patterns — diagnostic lenses, not destinies. Most people run multiple archetypes at once and cycle through them across seasons. The purpose of recognition is repentance, not self-labeling.
