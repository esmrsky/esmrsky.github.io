The Glossary

Every term reads in one plain sentence. If you want more, open “go deeper” — same card, second layer. Diagrams below for the three mental models that matter most.

Mental model #1 — How the web works

Every page load, everywhere, forever: your browser asks, a server answers. Frontend code travels to the browser; backend code and the database stay on the server.

Mental model #2 — Branch, commit, merge

The main branch stays safe while work happens on a feature branch. Each dot is a commit (a snapshot). The pull request is the moment of review before the branch merges back in. This loop is all of modern collaboration — human or AI.

Mental model #3 — The agent loop (how Claude Code works)

An agent isn't a smarter chatbot — it's a model in a loop with tools. It acts, observes the result, and corrects. Your job sits at the two ends: a clear spec going in, real review coming out.
