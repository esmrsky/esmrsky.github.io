So what do you do with this?

🔄 Keeping this page honest

Every rating on this page lives in data/landscape-data.js — one editable file. When the landscape shifts (it will), open this project in Claude Code and say: “research the current state of AI coding capabilities and update landscape-data.js, keeping the same format.” A capability page that can't be cheaply updated becomes misinformation within months; this one is designed to be refreshed in five minutes.
