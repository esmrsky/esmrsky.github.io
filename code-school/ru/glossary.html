Каждый термин читается в одном простом предложении. Если хочется больше, открой «копнуть глубже»: та же карточка, второй слой. Ниже — диаграммы для трёх самых важных ментальных моделей.

Ментальная модель №1 — как работает веб

Каждая загрузка страницы, везде и всегда: браузер спрашивает, сервер отвечает. Фронтенд-код едет в браузер; бэкенд-код и база данных остаются на сервере.

Ментальная модель №2 — ветка, коммит, слияние

Ветка main остаётся в безопасности, пока работа идёт в отдельной ветке фичи. Каждая точка — коммит (снимок). Pull request — момент проверки перед тем, как ветка вольётся обратно. Этот цикл и есть вся современная совместная работа, человеческая или с ИИ.

Ментальная модель №3 — цикл агента (как работает Claude Code)

Агент — это не чат-бот поумнее, а модель в цикле с инструментами. Она действует, смотрит на результат и поправляет себя. Твоя работа — на двух концах: чёткая постановка на входе и настоящая проверка на выходе.
