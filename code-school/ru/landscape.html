🔄 Как не дать этой странице устареть

Каждая оценка на этой странице лежит в data/landscape-data.js — одном редактируемом файле. Когда ландшафт изменится (а он изменится), открой проект в Claude Code и скажи: «изучи текущее состояние возможностей ИИ для кода и обнови landscape-data.js, сохранив тот же формат». Страница о возможностях, которую нельзя дёшево обновить, за несколько месяцев превращается в дезинформацию; эта рассчитана на обновление за пять минут.
